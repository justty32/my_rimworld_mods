# Task 9: 實機 E2E 驗證（手動清單）

**前置**：RimWorld 1.6 本體；`sims-mode-community/` 與 `npc-outposts/` 都複製/junction 進 `Mods/` 並啟用（順序：sims-mode 在前）。結果記入 `npc-outposts/session_log.md`，commit 訊息 `test: npc-outposts 實機 E2E 驗證記錄`。

對應 spec §9 完成定義，逐條打勾：

- [ ] **1. 開新世界分布**：生成新世界進遊戲 → 世界地圖上 NPC 聚落周圍出現哨站圖標（距離 2~4 格、每聚落 0~2 個——上限 1~3 的下半）；點選哨站，名稱為「<母聚落名>哨站」、派系正確。dev log 無紅字。
- [ ] **2. 舊檔增生**：開 dev 快轉（或掛機數遊戲日）→ 未達上限的聚落周圍隨時間長出新哨站；達上限後停止。另測：載入一個裝 mod 前的舊存檔 → 讀檔後立即長出基底哨站。
- [ ] **3. 拜訪小圖＋作息**：商隊走到中立哨站，右鍵 → 有「進入○○哨站」選項 → 進入後地圖為 150x150、聚落建築群、守軍人數明顯少於正常聚落（約 4 成）→ 守軍有 sims-mode 作息（白天工作台/田地假工作、傍晚聚會、夜間睡床；dev 調時辰驗證）。
- [ ] **4. 交易**：商隊停在哨站格 → 出現交易 gizmo → 能開交易視窗（存貨為派系 baseTraderKinds）。
- [ ] **5. 攻打**：右鍵哨站選攻擊（或停格後 gizmo）→ 生成小圖、收到關係懲罰信（與攻打聚落同款）→ 清空守軍 → 哨站從世界地圖移除、原地出現廢墟（DestroyedSettlement）。
- [ ] **6. 海盜哨站**：永敵派系聚落周圍也有哨站；右鍵無「進入」（Visitable=false）、可攻擊。
- [ ] **7. 真訪問原版聚落（sims-mode 交付驗證）**：右鍵任一中立**原版聚落** → 多出「進入○○」選項 → 生成全尺寸圖、活聚落作息正常；原版「拜訪（停格）」「攻擊」選項都還在且行為不變。
- [ ] **8. 存讀檔**:
  - 拜訪哨站途中存檔→重讀：無紅字、地圖/守軍/作息保持。
  - 大地圖存讀：哨站仍在、母聚落引用存活（dev 檢查或攻下母聚落觀察）。
  - dev 毀掉母聚落 → 存讀 → 無紅字、孤站保留。
- [ ] **9. 缺相依**：mod 列表停用 sims-mode → 管理器顯示 npc-outposts 缺相依警告；（若仍強行進遊戲，記錄行為即可，不要求無錯）。
- [ ] **10. 已接受行為觀察**（記錄即可，不算失敗）：任務系統是否選中哨站當目標；空投攻擊哨站是否全尺寸圖；派系最後聚落被滅但哨站存活時派系未判定全滅。

**回歸**：sims-mode 原 E2E 重點抽查——攻打中立原版聚落仍生效（活聚落接管+防禦切換）、敵對聚落攻打不受影響。
