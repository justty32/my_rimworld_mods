## §0. 觸發地基：信件 → 接受/拒絕 → 才召帶對話的訪客

**為什麼改**（部署側 E2E 回覆，使用者拍板）：現行「對話隨機掛在隨機鼠族訪客頭上＋殖民地狀態閂」→ 連 dev 都刷不出對話泡泡、正常玩很可能整局遇不到、也測不動。改成信件制：**可預期、可測、玩家有選擇權、不會錯過**，且這本就是使用者最初的構想（「有天一個可接受任務出現→接受→鼠族上門」）。

**機制**（每條主線＝薄 QuestScriptDef ＋ 現有 DialogTree 機器，職責分離）：
1. **QuestScriptDef**（storyteller 依權重/天數提供，玩家在任務欄看到＝可接受/拒絕的任務信）。gate＝**據點身份**（`State_Crafter`＝鐵匠屋／`State_Martial`＝傭兵團，由 F7 側寫器寫）＋前置（天數、名聲階層）。
2. **接受 → 自製 `QuestNode_SpawnRatkinEnvoy`（C#，待寫）**：在殖民地生一小隊鼠族訪客，用已證實的 `GameComponent_Editor.Component.AddDialog(pawn, dm)` 把該線的 `DialogManagerDef` 掛到帶頭那隻；做一個到訪 Lord（`LordJob_VisitColony`，訪畢自行離開）。
3. **玩家與帶頭訪客對話 → 現有 DialogTree 機器**（選項、`CQFAction_Quest` 觸發子任務、`requiredThings`/品質門檻交貨、`Ev_*` 記善惡名聲、`CQFAction_Faction`+`SetName` 具名加入……全部照舊）。
4. **拒絕 → 任務結束，無事**。

> ✅ 已坐實：自製 C# 子類能被 CQF 的 XML 反射載入＋在 runtime 執行（令狀召友軍實跑成功）；`AddDialog` API 存在。
> ⚠ 待實作前查：訪客團生成（`PawnGroupMakerUtility`/`GeneratePawn`）＋`LordJob_VisitColony` 簽名。
> **純風味閒聊線（Minstrel/Healer/Junk…）可維持隨機當「彩蛋」，主線務必信件化。**
> QA 便利：可加 dev debug action「直接發某條任務信」，省等天數。

## §1. 鐵匠屋（The Forge）——據點角色＝武器裝備生產者【使用者細化：層級委託系統】

**在講誰的故事**：上門求購/委託軍械的各路客人——由小到大：村莊、遊商、城鎮、傭兵團伙，最後是王國。**你＝這一帶的軍械名匠，名聲越大、客人越大。**
**名聲軸**：`Rep_WeaponMerchant`（每個委託完成都提供名聲）。**身份 gate**：`State_Crafter`（工匠主導）。

### 1a. 層級系統（核心結構）

委託分**三層**，靠 `Rep_WeaponMerchant` 累積解鎖高層；**低層不消失、只是佔比下滑**；**層內委託順序隨機打亂**。

| 層 | 解鎖 | 客戶 | 委託型態 | 報酬量級 |
|---|---|---|---|---|
| **T1 基層** | 開局起（先做這層） | 附近**村莊**、**小遊商** | 買**現貨/制式武器**（數量單，不挑品質） | 小 |
| **T2 進階** | 名聲達門檻 **M1** | **城鎮**、**較大遊商**、**傭兵團伙** | **★開始有專門定製**（品質門檻單：指定品質/類型） | 中 |
| **T3 王庭** | 名聲達門檻 **M2** | **王國採購官**（最難） | **量大、出價低**；失手可能掉派系關係 | 大但薄利 |

- **佔比機制**：每層委託信各有 selection weight，高層達門檻才進池；高層加入後低層自然佔比下滑（低層 weight 不歸零、只是被稀釋）。層內抽哪個客戶/委託＝隨機。
- **⚠ F8 帳本要擴充**：`Rep_WeaponMerchant` 現在只有單一 `≥25` bool；層級制要**分級門檻**（寫 `Rep_WeaponMerchant_T1/T2/T3` 或數值級 bool）。

### 1b. 客戶池：預定義具名客戶，每個名稱一條線【使用者定案】

- **預先定義一個客戶池**——一份固定名冊，每層若干具名客戶（都只是「名稱」：村莊名/商號/傭兵團名/採購官名）。**每個名稱＝一條自寫對話線**（客戶名字寫死在他自己的三語 Keyed 文案裡，不做動態注入）。
- 例：T1「橡實村」「碎碎念的貨郎擔」…；T2「鐵爐鎮」「赤爪傭兵團」「某某商會」…；T3「王國採購官某某」。名稱走鼠族名庫風格（自然/堅果/鐵系）。
- **★鼠族設定（見 [`../WORLDVIEW.md`](../WORLDVIEW.md)，硬約束）**：男女比 1:10、二次元可愛風、**都很年輕（無老者）**。**客戶/代表預設全女性（她）；男鼠稀有＝純背景比例，偶爾一個即可、不特別做梗**（護送稀有男鼠那類專門橋段作廢）。調性 moe、討喜、有反差萌，即使硬題材（傭兵/軍閥）鼠族本身仍可愛。**別寫成老倌/太爺/夫人這種年長口吻**——村長/採購官/團長都是年輕的（大姊姊/小隊長感）。DeepSeek prompt 要明講這幾點。
- **每個具名客戶各帶自己的關係狀態**（存 F8 帳本，以客戶 id 為 key）：
  - `滿意度計數`（每次好好完成 +1）、`blocked` 旗標（被敲詐後不再上門）、可選 `完成次數`。
- **「這個客戶還來不來」＝讀他自己的狀態**：層級解鎖 且 未 blocked → 他的委託信會進池；池中依 pacing/權重抽哪個具名客戶這次上門。
- **好處**：世界由一批**有名有姓、有記憶的回頭客**組成（你和「赤爪傭兵團」「橡實村」各自建立關係）＝北極星沉浸感；且**無需動態改名**、純授權內容（每客戶交 DeepSeek 寫），量產順。

### 1b-2. 每個委託通用的分支與後果（善惡/名聲織入）

- **敲詐勒索、開高價** → `Rep_WeaponMerchant` **降** ＋ **該具名客戶 `blocked`（此後他不再上門）**。（可並 karma−。）
- **武裝傭兵團伙/惡徒** → karma **降**（`Ev_Cruelty`）——賣給誰是道德選擇。
- **某具名客戶「次次都完成得很好」** → 他的滿意度累積達門檻 → **★該客戶專屬神祕獎勵**（見 1c）。
- **拒絕供貨村莊**（某村莊客戶的委託不接/回絕）→ 可能觸發**該村莊覆滅**後續事件（世界聚落被毀＋一封後果信；karma− 或愧疚 thought）。

> **要新做的狀態**：F8 帳本擴充 **per-客戶滿意度 int ＋ blocked bool**（以客戶 id 為 key，複用帳本現有 dict 模式）。這是本細化最大的新機制，但因「每名一條線」而不必動態注入名字——工程可控。

### 1c. 神祕獎勵（客戶忠誠度回饋）

- **傭兵團伙**（次次做好）→ **助戰契約**（傭兵版「召兵契約」，複用令狀機制 `CompUseEffect_RatkinAid`，改召傭兵援軍）。
- **遊商/城鎮**（次次做好）→ **折扣/優先供貨**（機制待研究：持久折扣 CQF 難做→可能改成「定期送好貨」旗標）。
- **★王國採購官**（最難、但持續每次都做好）→ **敵國奴隸 pawn**（Ideology 奴隸）／**傳家藝術品**（高值 art ThingDef）／**助戰契約**。

### 1d. 王國採購官（T3，最難）特點
- **量大、出價低**——利薄、考驗產能。
- **失手/違約 → 可能降 `Rakinia` 派系關係**（不只丟名聲，動真好感）。
- **持續每次都做好 → 特別獎勵**（敵國奴隸/傳家藝術品/助戰契約，見 1c）。

### 1e.（選）對手鐵匠
- 同行鼠族來踢館/削價/散布你劣製謠言，或約一場鍛造較量。純風味加厚，後續再說。

> **舊 A1–A4 的歸位**：A1 王國採購＝**T3**（已建，改信件制＋接上「持續做好→特別獎勵」）；A2 騎士訂製＝**T2 定製客戶**之一；A3 傭兵買軍火＝**T2 傭兵團伙客戶**（含武裝惡徒的 karma 分支）；原 A4「傳奇委託」＝可作 T3 或「王國/名將客戶忠誠獎勵」路線的頂點。

## §2. 僱傭兵團（The Company）——據點角色＝接軍事委託的據點

**在講誰的故事**：需要武力的委託人——受威脅的村落、要護送的商隊、開懸賞的掮客、交戰的派系。**你＝賣命的傭兵。**
**名聲軸**：`Rep_Mercenary`（接活打仗累積）＋**善惡分岔**（乾淨活 vs 髒活）。**身份 gate**：`State_Martial`（武力主導）。

### B1. 懸賞：軍閥據點 【已建，改信件制】
- 現況＝`QuestScript_RaidOutpost`（掮客付錢清軍閥營，`site.AllEnemiesDefeated`）。**動作：改信件觸發**（掮客的懸賞信）。乾淨活（打劫掠者），`Rep_Mercenary`+、karma 中性/+（`ProtectWeak`）。

### B2. 護送商隊
- **普通任務**：一名商人僱你護送商隊穿越險地。
- **選項分支**：
  - 信守契約、力戰護貨 → `Rep_Mercenary`+、商人好感、karma 中性/+。
  - 中途遇襲、拿錢跑路棄客 → `Ev_Betray`（karma−）、`Rep_Mercenary`−。
  - 對窮客免收護衛費 → `Ev_Charity`（karma+）。
- **機制（新，待定深度）**：護送＝世界地圖旅程 vs 簡化成「途中在你聚居點附近生一波伏擊、擊退即算護成」。**建議 v1 走簡化版**（複用 F6 fire-raid/F5），世界旅程列精修。

### B3. 保衛客戶
- **普通任務**：一個鼠族村落受軍閥威脅，僱你守衛（來襲打到你場上，複用 F6；或你出兵到他們的 site，複用 F5）。
- **★選項分支（juicy）**：
  - 力戰退敵 → `Rep_Mercenary`+、村落好感、karma+。
  - **敵方出更高價收買你倒戈** → 大筆白銀＋軍閥好感，但 `Ev_Betray`（karma−−）。
- **意義**：傭兵的經典道德困境，善惡完全由玩家一念。

### B4. 髒活委託
- **名聲回寫觸發**：這條的**出現機率隨你的暗黑傾向升高**（`Rep_Assassin`/`Rep_Mercenary` 高、或 `Karma_Evil`）——**壞名聲招來髒活**（用 `DialogCondition_Chance` 或帳本擲骰 gate）。
- **普通任務外殼**：掮客開懸賞，要你到某聚落「處理掉」一個特定目標（複用 F5 `conditionCauser.Destroyed` 暗殺骨架）。
- **選項分支**：
  - 接下、幹掉目標 → `Ev_Assassin`（暗殺名聲+、karma−）、重酬。
  - 接了但只嚇阻/放走 → 少酬、無 karma 損。
  - 回絕 → 無。
- **意義**：傭兵**自然滑向**暗殺——不是專線，是接髒活接出來的。這正是使用者要的「善惡自然體現」。

### B5. 老兵入夥（具名加入）
- 一位歷經風霜的鼠族**女**傭兵（戰鬥版的胡桃），跨幾次委託的短弧；依你的抉擇，結局**加入你的傭兵團當殖民者**（複用 `CQFAction_Faction`+`SetName`+gender）。給傭兵團家族一個具名情感錨。

## §3. 善惡/名聲「織入」慣例（可複用寫法）

- **每個委託/訂製 ≥1 個慷慨選項（karma+）＋≥1 個自利/殘忍選項（karma−）**；照常玩就會累積。事件旗標用 F8 現成的 `Ev_Charity/Mercy/ProtectWeak/WeaponDeal/MercWork/Cruelty/Betray/Assassin`。
- **名聲回寫（兩向）**：
  - **解鎖規模**：`Rep_WeaponMerchant` 高→A2 騎士找上門、A4 傳奇委託解鎖；`Rep_Mercenary` 高→更大懸賞、客戶專程找你。
  - **暗黑招髒活/嚇跑好客**：`Rep_Assassin`/`Karma_Evil` 高→B4 髒活出現機率升、且護送/保衛類「乾淨客」可能不信任你（少來）。
- **跨家族綜效**：又工匠又武力的據點兩族都見；名匠高名聲觸發傳奇委託；傭兵暗黑名聲觸發暗殺。
- **身份由據點狀態自然決定**（`State_Crafter/Martial`，側寫器寫）＝北極星「身份＝功能，決定誰上門」。玩家自宣告身份仍為**輔助**、非必需。

## §4. 建置順序 ＋ 新機制風險旗標

1. **地基**：自製 `QuestNode_SpawnRatkinEnvoy`（信件→接受→召訪客+AddDialog）；**拿 T1 村莊/小遊商買現貨當試點**（最單純，先把觸發鏈跑通、送測驗一輪）。→ 驗過，全家族才鋪得動。
   - 同批做 **F8 帳本擴充**：`Rep_WeaponMerchant` 分級（T1/T2/T3 門檻）＋ **per-客戶關係狀態**（滿意度計數 + blocked 旗標）。
2. **鐵匠屋（照層級由低到高）**：**T1 村莊/小遊商** → **T2 城鎮/大遊商/傭兵團伙（起有定製＋忠誠神祕獎勵）** → **T3 王國採購官（改造已建的 A1，接上派系關係風險＋特別獎勵）**。含通用分支（敲詐→名聲降+客戶斷、武裝惡徒→karma−、拒供村莊→覆滅後果）。
