## 一、新增子系統 F8：善惡值＋分類名聲帳本（軟門檻）

**你要的**：玩家在任務線中的選擇改變善惡值；完成的任務種類改變聚居點偏向；據此讓某些任務內容變化、甚至難以觸發；但**用幾率、別限太死**。

**怎麼做的**（`Source/GameComponent_RatkinLedger.cs`，已編譯）：
- CQF 全域狀態只有 bool，數不了「累積」。所以照 F7 側寫器的成功模式，寫一個存檔級 `GameComponent` 持有數值並持久化。
- **橋接**：對話選項用 `CQFAction_SetGlobalBool` 設一個一次性「事件旗標」`RatkinQL_Ev_*`；帳本每 500 tick 掃描、消費（歸零）這些旗標，把 delta 累加進 `karma:int` 與 `rep[type]:int`。
- **事件→數值對照表**（節錄）：`Ev_Charity` 善+10、`Ev_Cruelty`（趁火打劫）善−8、`Ev_ProtectWeak` 善+8、`Ev_Assassin` 暗殺善−8＋暗殺名聲+12、`Ev_WeaponDeal` 軍械商名聲+12、`Ev_FoodDeal` 農產商名聲+12、`Ev_MercWork` 傭兵名聲+12…
- **回寫階層 bool**（給對話端 `DialogCondition_Bool`/`genrationConditions` 讀）：`RatkinQL_Karma_Good/Evil/NotEvil`、`RatkinQL_Rep_Merchant/WeaponMerchant/FoodMerchant/Mercenary/Assassin`。
- **軟門檻（用幾率）**：`RatkinQL_Soft_OrphanOk` 每 2500 tick 擲骰，機率 = f(善惡值)×(暗殺名聲抑制)。**做多降善惡的暗殺 → 善惡值低＋暗殺名聲高 → 託孤/收養類任務自然難觸發**（正是你舉的例）。門檻寬鬆、非硬鎖。

**已驗證**：編譯過、SetBool/GetBool API 與 F7 同源（F7 已實機實例化過）。
**待實機**：事件旗標的消費時序、擲骰 gate 的體感頻率。
**我的疑慮**：
1. 事件旗標若在帳本消費前被同一選項重複觸發（理論上不會，但值得實機看一眼）。
2. 目前**沒有任何既有任務去「讀」這些名聲階層**——F8 只是鋪好地基＋武器商線用了 `State_Crafter/Martial`。要不要我回頭把既有 20 條線接上（例：託孤線 LostKit/Refugee 加 `Soft_OrphanOk` 條件；暗殺線 RaidOutpost 完成時設 `Ev_Assassin`）？這會讓「世界回應玩家」真正閉環。
3. 數值門檻（善±15、名聲25）是我拍的，需你調手感。

## 二、任務線 A：《商團首領佩林》三章劇情弧（含具名加入）

- **在講誰的故事**：**胡桃（Walnut）**——一隻**年輕母鼠**，某鄉下小貴族**佩林家（Peirin）的三女**，不甘被安排聯姻、困在莊園，偷跑出來帶著寒酸小商隊闖商路。要面子（有貴族教養）、天真莽撞、心底熱誠。**大家叫她胡桃；姓氏佩林她平時不提，只在夠信任時（Ch3 風光重逢＝善待路線才到得了）才娓娓道出身世**，那是全弧高光。名字取自鼠族 mod 名庫。
- **玩家聚居點扮演的角色**：她商路上的驛站／恩主。你怎麼待她，決定她的結局，也改你的善惡值與商人名聲。

**三章**（純對話＋全域 bool 分章閂，+1 個 site 子任務）：
| 章 | 觸發 | 玩家選項 → 後果（善惡/名聲掛鉤） |
|---|---|---|
| Ch1《破爛商團》 | 尚未認識佩林 | 公道買（商名+）／慷慨資助（善+，`Funded`）／壓價宰她（善−，`Fleeced`）／打發走 |
| Ch2《週轉不靈》 | 已認識、Ch2 未了 | 借週轉金（善+，`Helped`）／**替她出兵**（觸發 `QuestScript_PeirinAmbush` 清軍閥追兵營，勝→`Rescued`＋善+）／趁火打劫收光貨（善−，`Broke`）／回絕（`Broke`） |
| Ch3《結局》 | Ch2 已了 | 依累積旗標，用「選項條件+hideWhenDisabled」動態呈現：<br>● **風光重逢**（曾 Funded/Helped/Rescued）→ 她成了像樣行商，回來送厚禮<br>● ★**破產求收留**（Broke：你坑過她/見死不救）→ 她一無所有找上門，可**收留她加入殖民地** |

**★具名加入（你最期待的獎勵）**：Ch3「收留」選項＝`CQFAction_Faction` 收編對話對象成殖民者 ＋ 自製 `CQFAction_SetName` 正名為「Peirin Walnut」並**強制設為母鼠**。

**已驗證**：全對話樹/分章閂/site 子任務骨架＝本包已實機驗證過的積木（F1 對話機制、F5 site 骨架 `Util_GenerateSite`+`site.AllEnemiesDefeated`、`CQFAction_Faction` 收編＝F3 用過）。靜態全綠。
**待實機**：`CQFAction_SetName`（新自製）實際改名＋改性別＋刷新外觀；分章 bool 的體感節奏。
**我的疑慮（請重點看）**：
1. **加入者的「外形/能力固定」目前只做到名字＋性別**。收編的是「當下那位帶著本章對話的鼠族訪客」，改名改性別，但**外觀/技能仍是隨機**。你之前要「外形能力都固定」——要做到，得走另一條路：建一個**專屬母鼠 PawnKindDef（固定背景/技能/服裝）**，加入時直接生成她為殖民者（用 CQF 的 `PawnSpawnData`，可帶 faction=玩家）。我沒直接上這條，因為它是本包**沒驗證過**的生成路徑（dialog 內生 pawn＋faction=玩家），我想先要你點頭再投入實機驗證。**要 A（現在這版：可靠、名字性別固定）還是 B（專屬 PawnKind：外形能力全固定，但要冒實機驗證險）？**
2. 分章弧靠「同時只有一章的 DialogManager 能綁」的全域 bool 閂。若玩家長期不遇到鼠族訪客，弧會停滯（合理，但你可能想加個保底）。
3. 中文用音譯「佩林」、殖民者英文名 "Peirin Walnut"——你接受這種 EN/中文名並存嗎？

## 三、任務線 B：《鼠族王國軍械採購》武器商線（招牌獎勵：召兵號角）

- **在講誰的故事**：**Rakinia 王國這個派系**的軍需後勤——你成為王室認可的軍械供應者（呼應你說「表現一個團體/派系的故事」）。
- **玩家聚居點扮演的角色**：軍械工坊／武器商。所以入口用 `genrationConditions` 篩「聚居點偏武備」（`State_Crafter` 或 `State_Martial`，F7 側寫器寫入）——**身分＝功能，賣武器的才會被王國找上**。

**兩幕**：
1. 《王國信使》：信使（正式官腔）登門發採購令 → 接下設 `Arms_Active`。
2. 《軍需官收貨》：軍需官到訪驗貨，**要交 3 把「優良(Good)以上」的長劍**（★品質門檻，自製 `DialogCondition_ThingQuality` 閂選項、`CQFAction_ConsumeQualityThings` 依品質扣料，不誤扣爛貨）→ 交付得**白銀 200 ＋《王國徵召令狀》**（`RatkinQL_KingdomTally`）。

**★品質門檻（已按你 #3 做）**（`Source/QualityDelivery.cs`，已編譯）：`requiredThings` 認不了 quality，故自製一對 C#——條件掃玩家地圖，要有 ≥3 把品質達標的長劍才顯示交貨選項；扣料時優先扣達標的。真品質門檻＋品質正確扣料。
**★徵召令狀（已按你 #3 改：號角→一紙契約）**（`CompUseEffect_RatkinAid.cs`＋`Things_RatkinQL.xml`，已編譯）：**一紙只能用一次、用過即毀的契約**；動用後一隊鼠族王國友軍從地圖邊緣走入協防——原版「盟友軍事支援」同機制（`RaidFriendly`+`ImmediateAttackFriendly`+`EdgeWalkIn`）。貼圖借原版捲軸（Schematic）。

**已驗證**：對話樹/交貨扣料/獎勵道具 def 型別；`RaidFriendly`/`ImmediateAttackFriendly`/`CompQuality` 皆反編譯確認。C# 全編譯過。
**待實機（本輪最高風險項）**：①令狀觸發友軍 raid 的整條鏈；②自製品質條件/扣料在真地圖上掃 `listerThings` 的行為。
**我的疑慮**：
1. **扣料掃的是「地圖 listerThings」**（堆在殖民地的長劍）——裝備在身上的、caravan 裡的不算。交貨在殖民地應足夠，但值得實機看邊界。
2. **交貨地點**：目前只做「軍需官到殖民地收」。你原案還有「caravan 到鼠族聚落交付」——要 OA_Frame 可互動世界據點，較重，列後續。
3. **令狀召兵目前即時、無延遲**：你原案想「一兩天內到達」。令狀已是單次即毀（符合你 #3），但**到達延遲**還沒加——要加嗎？
4. 這條線 v1 仍是**一次性**（`Arms_Done` 後不再刷）。要做成可重複、大單需 `Rep_WeaponMerchant` 夠高才觸發嗎？（接 F8。）
