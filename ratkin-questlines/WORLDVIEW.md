# WORLDVIEW — 鼠族設定硬約束（生成文案/角色的權威規範）

> 這是本 mod 一切鼠族內容（對話、任務名、角色、信件、背景）的**硬約束**。
> 動筆或下 DeepSeek/agy prompt 前先讀本檔；prompt 要把下列各點**明講**。
> 敘事筆法/命名庫另見開發區 `analysis/narrative-tone/`（鼠族＝ `ratkin.md`）。

## 鼠族基調（使用者定調 2026-07-18～19）

- **男女比 1:10（約九成女性）。**
- **二次元、很可愛（moe）風格**——不是硬派寫實。
- **都很年輕，沒有老者。**

## 生成規則

- **性別預設＝女性（她）。** 具名客戶/訪客/信使/採購官、隨機來客——絕大多數是母鼠。
  DeepSeek/agy prompt 要明講「除非特別指定，鼠族角色一律女性、用『她』」。
- **都很年輕**：全員青春/少女感，**不要老者**（別寫成老倌、老嫗、太爺、夫人這種年長口吻）；
  即使是村長/採購官/傭兵團長，也是年輕的（大姊姊/小隊長那種），別倚老賣老。
- **男鼠稀有（約 1/11）＝純背景比例**。偶爾出現一個即可，**不特別為男鼠做梗/任務**
  （不搞「稀有男鼠被珍視／護送稀有男鼠」那類專門橋段）。仍是「別隨手把角色寫成男的」，預設女性。
- **調性＝二次元可愛（moe）**，不走陰暗寫實。即使是傭兵團/軍閥衝突/暗殺這種硬題材，
  鼠族本身讀起來要**可愛、討喜、有反差萌**。既有 mod（NewRatkinPlus）本就是可愛鼠人 race。
- **名字走鼠族名庫風格**（花草/堅果/鐵系），見 `analysis/narrative-tone/ratkin.md`。
- **具名客戶名冊預設全女性**；若放一兩個男性客戶，當「稀有/特別」來寫。
